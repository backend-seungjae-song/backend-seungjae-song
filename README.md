# 송승재

커머스 백엔드, AI 서비스와 도구 개발

AI를 쓰면서 당연하다고 여겼던 것들을 직접 실험해서 확인하고 있습니다.

커머스 백엔드를 개발하며 사내 AI 도입을 맡고 있습니다. 반복 정산 업무를 AI 스킬로 만들었고 사내 AI 사용량을 확인하는 대시보드와 월간 집계 도구를 개발했습니다.

숏폼 영상의 주제 선정부터 대본 작성, 음성과 이미지 생성, 편집과 출력까지 자동화하는 시스템을 혼자 개발했습니다. 영상팀에서 제작 노하우와 결과물 피드백을 받고 있습니다.

여러 코딩 에이전트와 브라우저, 문서를 함께 다루는 macOS 앱을 만들어 쓰고 있습니다. 화면에서 고른 작업 대상의 정보를 에이전트에 전달하도록 구현했습니다. AI에 주는 지시와 자료를 바꿔 보며 답변 품질과 사용량을 비교하고 있습니다.

## 개발 경험

2021년부터 앱과 웹 서비스를 개발해 왔습니다. 서비스 품질 검수를 이어받아 상태 관리와 개발 환경을 정비했습니다. 개발자 지식 공유 모임을 만들어 주간 세션을 운영했습니다.

2026년 1월부터 병역대체 복무 중입니다.
