## Iris: 직접 만들어 쓰는 AI 개발 환경

AI와 함께 개발할 때 쓸 macOS 앱 Iris를 만들어 사용하고 있습니다. 여러 코딩 에이전트의 작업 세션, 브라우저, 문서를 한 화면에서 다루도록 구성했습니다. 화면에서 고른 작업 대상의 정보를 에이전트에 전달하고 지정한 브라우저에서 작업하도록 구현했습니다.

## 업무에 적용한 자동화

커머스 백엔드를 개발하며 사내 AI 도입을 맡고 있습니다. 반복 정산 업무는 자료 비교와 불일치 분석부터 데이터 수정, 결과 재검증까지 직접 수행했습니다. 이 절차를 AI 스킬로 만들어 반복 작업에 적용했습니다.

숏폼 자동 제작 시스템은 주제 선정부터 대본 작성, 음성과 이미지 생성, 최종 영상 출력까지 혼자 개발했습니다. 영상팀에서 제작 노하우와 결과물 피드백을 받고 있습니다.

## 실험으로 확인하는 판단

AI에 주는 지시와 자료를 바꿔 가며 답변 품질과 사용량을 비교하고 있습니다. 자료를 전달하는 프로그램을 만든 뒤 중복 읽기 때문에 입력이 늘어난 것을 확인하고 전달 과정을 수정했습니다. 블로그에는 효과가 있었던 조건과 기대와 달랐던 결과를 함께 기록하고 있습니다.
