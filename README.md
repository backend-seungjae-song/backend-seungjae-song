# 송승재

2021년부터 앱과 웹을 개발했고 지금은 리워드 앱과 커머스 백엔드를 맡고 있습니다. 개인 프로젝트로 AI 개발 도구와 캐릭터 챗 서비스를 만들고 있습니다.

## 리워드 앱과 커머스

리워드 앱을 전면 개편하면서 가입과 로그인, 상점, 응모, 포인트 정책을 새로 구현했습니다. 정책 문서가 없는 상점은 실제 구매 화면에서 호출하는 코드를 따라가며 새 앱에서도 유지할 동작을 정했습니다.

커머스에서는 쿠폰 결제와 환불을 개발했습니다. 같은 상품의 부분 취소 요청이 겹쳐 금액이 두 번 차감되던 문제는 주문 상품을 먼저 잠그고 취소 이력을 확인하도록 바꿔 해결했습니다.

## AI를 활용한 개발 도구

[Iris](https://github.com/backend-seungjae-song/Iris)는 직접 써 본 오픈소스를 조합해 만든 개인용 IDE입니다. 터미널과 브라우저 제어에는 기존 도구를 쓰고, 고칠 화면을 클릭해 Claude Code나 Codex에 전달하고 변경 내용을 확인하는 기능은 제 작업 방식에 맞춰 만들었습니다.

업무에서는 DB 조회용 MCP를 만들었습니다. AI가 SQL을 실행하거나 파일에 쓰기 전에 실제 스키마와 대조해 없는 테이블이나 컬럼을 참조하면 차단합니다. 정산 금액이 맞지 않는 거래를 찾아 원인과 수정 SQL을 정리하는 Claude Code 스킬도 만들어 동료들과 쓰고 있습니다.
