# 송승재

업무 자동화와 AI 개발 도구를 만드는 소프트웨어 엔지니어입니다.

문제의 원인과 구현한 결과를 직접 확인하며 함께 일하는 사람의 신뢰를 얻으려 합니다.

## [Iris](https://github.com/backend-seungjae-song/Iris)

여러 코딩 에이전트와 브라우저, 문서를 한 화면에서 다루는 macOS 앱을 개발해 사용하고 있습니다. 사람이 고른 작업 대상을 에이전트에 전달하도록 구현했고 코드를 공개했습니다.

## 숏폼 제작 자동화

주제 선정부터 대본 작성, 음성과 이미지 생성, 최종 영상 출력까지 단독으로 개발했습니다. 영상팀의 제작 노하우와 결과물 피드백을 반영했습니다.

## 정산 업무 자동화

자료 비교와 불일치 분석, 데이터 수정과 재검증까지 직접 맡았습니다. 반복되는 정산 절차를 AI 스킬로 만들어 업무에 적용했습니다.

2021년부터 앱과 웹 서비스를 개발해 왔으며 현재 커머스 백엔드 개발과 사내 AI 도입을 맡고 있습니다. 2026년 1월부터 병역대체 복무 중입니다.
