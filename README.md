# 송승재

AI 서비스·도구 개발 · 커머스 백엔드

AI를 쓰면서 당연하다고 여겼던 것들을 직접 실험해서 확인하고 있습니다.

커머스 서비스의 백엔드를 개발하며 사내 AI 도입을 맡고 있습니다. 반복적인 정산 업무를 자동화하고, 사내 AI 사용 기록을 모으는 대시보드와 월간 집계 도구를 만들었습니다.

숏폼 영상의 주제 선정부터 대본·음성·이미지·편집·출력까지 연결한 시스템을 단독 개발했습니다. 영상팀으로부터 제작 노하우와 결과물 피드백을 받고 있습니다.

여러 코딩 에이전트와 브라우저, 문서를 연결하는 macOS 앱을 만들어 개발에 사용하고 있습니다. 화면에서 작업 대상을 고르면 관련 정보를 에이전트에 전달할 수 있습니다. 지시와 정보 전달 방식의 효과는 답변 품질과 사용량을 함께 비교해 확인합니다.

## 개발 경험

2021년부터 앱과 웹 서비스를 개발해 왔습니다. 기존 서비스의 품질 검수를 이어받고, 상태 관리와 개발 환경을 개선하는 일을 해 왔습니다. 개발자 지식 공유 모임을 만들어 주간 세션을 운영했습니다.

2026년 1월부터 병역대체 복무 중입니다.

AI를 쓰고 도구를 만들면서 확인한 것을 글로 씁니다. 실험을 다루는 글에는 비교 조건과 결과, 아직 확인하지 못한 부분을 함께 적습니다.
