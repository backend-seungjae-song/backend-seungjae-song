# 송승재

AI를 쓰면서 당연하다고 여겼던 것들을 직접 실험해서 확인하고 있습니다.

소프트웨어 엔지니어로 커머스 서비스의 백엔드를 개발하고 있습니다. 현 직장에 재직 중이며 2026년 1월부터 병역대체 복무 중입니다.

## 지금 하는 일

- 사내 AI 도입을 맡고 있으며, 동료들이 각자 AI 사용 기록을 받아 볼 수 있도록 사용량을 측정하는 방법을 설계하고 있습니다.
- 여러 코딩 에이전트와 브라우저, 문서를 한 화면에서 다루는 개인 도구를 만들어 사용하고 있습니다.
- 지시문과 검사 프로그램, 작업 절차를 직접 만들어 쓰면서 어떤 지시가 결과를 바꾸는지 확인하고 있습니다. 모델과 과제가 달라지면 같은 방법도 다시 비교합니다.

## 글

AI를 쓰고 도구를 만들면서 확인한 것을 씁니다. 처음 접하는 분들을 위한 설명부터 시작하고, 실험을 다루는 글에는 비교 조건과 결과, 아직 확인하지 못한 부분을 함께 적으려 합니다.
